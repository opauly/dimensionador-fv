# VRM Monitor landing page

Marketing landing page pitching automated, branded performance reports built
from Victron VRM data — for solar installers (fleet subscriptions) and system
owners (single reports or a personal subscription).

Published at: https://claude.ai/code/artifact/02bb6db3-0530-4fe4-bdf3-e448f47ecfb6

## Files

- `landing_template.html` — editable source. Contains `__PLACEHOLDER__` tokens
  where fonts and images get inlined as base64 data URIs (required by the
  Claude Artifact CSP, which blocks external font/image requests).
- `assets/` — raw font (`.woff2`) and image (`.png`) files referenced by the
  template.
- `build.py` — substitutes the placeholders with base64-encoded asset data and
  writes `landing_page.html`, the self-contained file that gets published.
- `landing_page.html` — build output. Not hand-edited; regenerate with
  `python3 build.py` after changing the template or assets.

## Editing

1. Edit `landing_template.html` (and/or replace files under `assets/`).
2. Run `python3 build.py` from this directory.
3. Open `landing_page.html` directly in a browser to preview, or publish it
   via the Artifact tool to the URL above to update the live page.

The sample report screenshot (`assets/sample_report.png`) shows a synthetic
household — generated by running the real report pipeline
(`victron/weekly_report.py`) against fabricated CSV data, so the narrative and
savings numbers are authentic pipeline output but no real customer data is
shown.
